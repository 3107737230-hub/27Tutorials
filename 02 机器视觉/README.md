# 02 机器视觉

本目录提供见习队员的机器视觉实验与作业，使用 Python、OpenCV、VS Code 和 Jupyter。

- [实验入口与环境配置](lab/README.md)：九个实验的说明、代码和本地图片。
- [一次实验作业](lab/assignments/README.md)：完成翻转、颜色调整、图像滤波，提交三张对比图和三句说明。
- [PR 提交步骤](lab/CONTRIBUTING.md)：通过一个 PR 提交到 `02 机器视觉/lab/submissions/自己的GitHub用户名/`。

克隆整个仓库后，在 VS Code 中打开本目录下的 `lab` 文件夹，按实验入口中的步骤安装环境并选择 Notebook 内核。
