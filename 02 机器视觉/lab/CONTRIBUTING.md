# 作业 PR 提交步骤

先完成 [作业要求](assignments/README.md)，再一次性提交三张图片和三句说明。

## 1. 准备自己的仓库和分支

将本仓库 Fork 到自己的 GitHub 账号，用 VS Code 克隆自己的 Fork 并打开项目。创建作业分支，例如 `assignment/你的GitHub用户名`，在这个分支中保存提交文件。

## 2. 整理文件

在 `02 机器视觉/lab/submissions/` 下新建以自己 GitHub 用户名命名的目录，将三张结果图复制进去，并用 [说明模板](assignments/submission_template.md) 填写 `README.md`。文件名按作业要求保留。

只提交自己的 `02 机器视觉/lab/submissions/你的GitHub用户名/` 目录。运行实验后，Notebook 和 `outputs/` 中可能显示为已修改；这些文件保留在本地，无需放进作业 PR。

## 3. 提交并推送

在 VS Code 的源代码管理中，只暂存自己提交目录中的四个文件，填写提交说明，例如“完成图像处理作业”，提交并推送到自己的 Fork。

## 4. 发起 PR

从自己的作业分支向教师仓库的默认分支发起 Pull Request。检查目标仓库和分支是否正确，然后填写：

- 标题：`[作业] 你的GitHub用户名`
- 描述：按模板勾选完成的项目；有问题可以在描述中说明。

提交前查看文件变更列表，确认只包含自己的三张图片和一个 `README.md`。提交后可在 PR 中查看图片和评语。

## 5. 根据评语补充

需要修改时，在原来的作业分支中更新文件，再次提交和推送，原 PR 会同步更新。无需再创建一个 PR。
