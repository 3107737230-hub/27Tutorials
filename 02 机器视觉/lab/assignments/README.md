# 一次实验作业

完成三个小任务后，通过 **一个 PR** 一次提交。只需要三张对比图和三句说明，无需提交 Notebook、代码或长篇报告。

## 任务一：水平翻转

打开 [实验三](../lab03_image_io/lab03.ipynb)，选择内核并全部运行。查看末尾的“作业：导出对比图”单元格，将生成的 `outputs/lab03/01_flip.png` 复制到自己的提交目录。

图片应包含原图和水平翻转图，能够看出左右方向的变化。可以使用默认硬币图片。

## 任务二：颜色调整

打开 [实验四](../lab04_color_adjustment/lab04.ipynb)，选择内核并全部运行。在“调整通道并迁移到熊猫图”单元格中找到：

```python
offset_bgr = np.array([0, 0, 40], dtype=np.float32)
```

将最后的 `40` 改成 `80`（也可以选择其他数值），重新运行该单元格，再运行末尾的“作业：导出对比图”单元格。将 `outputs/lab04/02_color.png` 复制到自己的提交目录。

图片应包含原图和颜色调整图，说明自己调整的是哪个通道。三个数字依次是蓝、绿、红通道的偏移量；不要求做颜色量化的参数比较。

## 任务三：图像滤波

打开 [实验八](../lab08_filtering/lab08.ipynb)，选择内核并全部运行。在末尾的“作业：导出对比图”单元格中，默认使用中值滤波处理带椒盐噪声的瓶盖图，生成 `outputs/lab08/03_filter.png`。将它复制到自己的提交目录。

图片应包含带噪声的输入和滤波结果，观察小黑点、小白点的变化即可。也可以选用提供的均值或高斯滤波代码。不要求提交 MSE、比较多个滤波器或调整多组参数。

## 提交内容

以下目录相对于本实验的 `lab/` 文件夹；在 GitHub 仓库中的完整位置是 `02 机器视觉/lab/submissions/你的GitHub用户名/`。

```text
submissions/
└── 你的GitHub用户名/
    ├── 01_flip.png
    ├── 02_color.png
    ├── 03_filter.png
    └── README.md
```

复制 [说明模板](submission_template.md) 作为自己目录中的 `README.md`，填写三句话即可。图片请使用本次运行得到的结果。

## 怎么交

按 [PR 提交步骤](../CONTRIBUTING.md) 操作，PR 标题填写 `[作业] 你的GitHub用户名`。三个任务放在同一个 PR 中；需要补充时，继续更新同一个 PR。

## 完成标准

采用“通过 / 补充后通过”：三张对比图完整、处理效果能辨认、三句说明与图片一致，即可通过。某种滤波效果不明显时，可以如实写出观察到的现象，无需为了得到特定结论反复调整参数。

九个 Notebook 中的其他参数练习与思考题供学习使用，不需要额外提交。
