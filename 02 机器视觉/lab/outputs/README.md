# 实验结果

每个 Notebook 将结果存入对应的 `lab01/` 至 `lab09/` 子目录。重新运行会覆盖同名结果图。Notebook 本身也会保留图像输出；整理实验记录时，可将 Notebook 与本目录一起保存。

实验六额外导出灰度直方图 CSV 与三维联合直方图 NPY，实验八额外导出 MSE 对比 CSV。`verification.json` 为实际验证时生成的运行记录；验证脚本需要从头执行所有单元格。

本次作业只需从实验三、四、八的结果目录中复制 `01_flip.png`、`02_color.png`、`03_filter.png` 到自己的 `submissions/` 子目录。无需把整个 outputs 目录提交到 PR。
