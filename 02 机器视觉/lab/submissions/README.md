# 作业提交目录

本目录位于仓库的 `02 机器视觉/lab/submissions/`。

每位见习队员使用自己的 GitHub 用户名建立一个子目录，放入三张结果图和一份简短说明。所有任务通过同一个 PR 提交。

```text
submissions/
└── 你的GitHub用户名/
    ├── 01_flip.png
    ├── 02_color.png
    ├── 03_filter.png
    └── README.md
```

具体要求见 [作业说明](../assignments/README.md)，提交方式见 [PR 提交步骤](../CONTRIBUTING.md)。不要改动其他队员的目录。
